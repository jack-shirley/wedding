# Kyra & Jack Wedding Website

Single-page static website for GitHub Pages.

## Setup

1. Add your engagement photo as `assets/engagement.jpg`.
2. Open `index.html` locally to preview.
3. Commit and push all files to your GitHub Pages repository.

Edit copy in `index.html`, styling in `styles.css`, and navigation behavior in `script.js`.

RSVP is intentionally a placeholder until you choose a form or RSVP provider. Wedding venue, lodging, and schedule are not yet finalized.
